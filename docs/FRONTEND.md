# Frontend Requirements

## Dashboard

Display:

- Total portfolio value
- Asset allocation
- Large/mid/small-cap split
- Gold/silver ETF allocation
- Mutual-fund allocation
- Rule compliance percentage
- Critical alerts
- Top stock candidates
- Mutual-fund candidates

## Stock analysis page

Sections:

1. Company overview
2. Business quality
3. Growth
4. Financial health
5. Cash flow
6. Valuation
7. Management
8. Moat
9. AI disruption
10. Industry/competitor comparison
11. Technical indicators
12. Score
13. Passed/failed rules
14. Investment thesis
15. Risks

## Mutual-fund page

Show:

- Category
- Benchmark
- Cost
- Returns
- Risk
- Rolling returns
- Portfolio concentration
- Overlap with user's funds
- SIP suitability
- Rule compliance

## Portfolio page

Use:

- Allocation chart
- Holdings table
- Rule status table
- Drift indicators
- Alerts
- Rebalancing suggestions

## UX principle

Do not make the user interpret 30+ metrics without context. Provide a summary first and allow drill-down into evidence.
