# Share Market Analysis Application

A long-term investment analysis web application for Indian stocks and mutual funds.

## Objective

The application evaluates stocks, mutual funds, and the user's portfolio against configurable investment rules and produces:

- Stock suggestions
- Mutual fund suggestions
- Portfolio compliance status
- Rule violations and warnings
- Long-term investment suitability
- Stock quality score out of 100
- AI disruption classification
- Industry and competitor analysis
- Popup notifications when the portfolio violates configured rules

## Core integrations

- Zerodha Kite / Coin MCP
- Groww MCP
- Market and financial-data providers
- AI/LLM service for qualitative analysis

## Investment horizon

- Equity: 3–10 years
- Mutual funds: 15 years
