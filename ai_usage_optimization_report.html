4. Repeated Task Detection

Tasks are classified into standard categories based on execution patterns:

  • Necessary: Independent scoring verification, schema updates, real-time quote refreshes.
  • Potentially Avoidable: Repeatedly reading static instructions or entire documentation files instead of targeted sections.
  • Unnecessary: Repetitive queries without parameter changes or re-generating identical boilerplate code.
  • Retry-Related: Re-execution caused by timeouts, rate limits, or transient connection errors.
  • Context Repetition: Re-transmitting large system prompts and full context windows when cached tokens could be leveraged.
